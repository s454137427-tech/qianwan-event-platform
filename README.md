# 前湾 MEGA 双赛事平台

可运行整理版 2.1.0（2026-10-08）。包含参赛网站、后台、报名、私有资料上传、作品审核、投票、评委评分和签到。当前可在本机运行，真实微信、腾讯云和子域名在资源配置后联调。

## 本地启动

需要 Node.js 24 或以上、pnpm 11.25.0。进入本目录：

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm run setup
pnpm start
```

也可双击 [启动预览.cmd](启动预览.cmd)。初始化会保留已经填写的配置。

- 网站：http://127.0.0.1:3000
- 后台：http://127.0.0.1:3000/admin.html
- 首次本机管理员账号和随机密码：`var/本地后台登录.txt`，请勿分享。
- 本地预览只监听本机，使用虚构资料和测试文件。

体验流程：体验昵称登录 → 报名 → 管理员核验 → 影像投稿，或造物录取与签到 → 作品审核 → 公众投票 → 评委评分。

## 正式接入

运行初始化后填写 `deploy/.env.production`，然后：

```text
pnpm deploy:prepare
pnpm deploy:check
```

`deploy:prepare` 从 `APP_ORIGIN` 生成入口域名配置；证书放入 `deploy/certs/`，微信域名验证文件放入 `deploy/wechat-verification/`。正式环境连接外部 PostgreSQL、Redis 和私有 COS，禁止体验登录。新正式数据库默认关闭报名与投票，验收后从后台开启。

具体资源字段、微信回调、服务器启动命令和验收顺序见 [接入与验收](deploy/接入与验收.md)。

## 哪些文件是运行代码

| 位置 | 用途 |
| --- | --- |
| `server.js` | 服务启动、端口错误处理和退出清理 |
| `lib/` | 配置、数据库、登录、上传、报名、投票与后台接口 |
| `web/` | 当前正式前端；所有接口连接本项目后端 |
| `scripts/` | 初始化、代码检查、配置检查、入口配置生成与打包 |
| `deploy/`、`Dockerfile` | 正式环境模板、双应用实例和 HTTPS 入口 |
| `test/` | 自动化验证；使用独立临时目录，不写入实际报名数据 |
| `var/` | 本地数据库、私有上传与初始后台凭据，不进入部署包 |
| `releases/` | 生成的干净部署包与 SHA256 校验文件 |

`public/`、`legacy-backup-*`、`client-review/`、`review-package-*`、`_publish_work/` 为历史或审阅内容，当前服务只提供 `web/`。历史材料保留，部署包按允许清单打包，不带这些副本、密钥、真实数据或已安装的依赖。

本地 SQLite 与正式 PostgreSQL 分开使用。原 `data/*.json` 不自动迁移；数据库初始化记录结构版本，不删除既有数据。后续结构变化应新增迁移版本。

## 开发与交付检查

```text
pnpm check
pnpm test
pnpm format:check
pnpm release
```

需要整理格式时运行 `pnpm format`。依赖版本由 `pnpm-lock.yaml` 锁定。
