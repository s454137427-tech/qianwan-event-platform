## 本地启动

需要 Node.js 24 或以上、pnpm 11.25.0。进入本目录：

```text
pnpm install --frozen-lockfile --ignore-scripts
pnpm run setup
pnpm start
```

也可双击 [启动预览.cmd](启动预览.cmd)。初始化会保留已经填写的配置。

- 网站：http://127.0.0.1:3000
- 后台：http://127.0.0.1:3000/admin.html
- 首次本机管理员账号和随机密码：`var/本地后台登录.txt`，请勿分享。
- 本地预览只监听本机，使用虚构资料和测试文件。

参赛流程：微信扫码 → 手机授权并确认 → 报名 → 影像投稿及审核 → 作品上墙 → 公众投票与评委评分。报名待审核或已通过时可先投稿；上墙前必须通过作者报名/身份核验及作品审核。未接入公众号时，扫码入口显示待开放；未显式开启开发体验时不显示昵称入口。自动化测试使用独立的本地测试账号；测试接口默认关闭，生产环境禁止开启。

取消活动的旧接口已关闭，现有历史数据库记录保留，不参与展示、审核、投稿或投票。

## 正式接入

运行初始化后填写 `deploy/.env.production`，然后：

```text
pnpm deploy:prepare
pnpm deploy:check
```

`deploy:prepare` 从 `APP_ORIGIN` 生成入口域名配置；证书放入 `deploy/certs/`，微信域名验证文件放入 `deploy/wechat-verification/`。正式环境使用 PostgreSQL、Redis 和私有 TOS，禁止体验登录。新正式数据库默认关闭报名与投票，验收后从后台开启。

具体资源字段、微信回调与原有操作见 [接入与验收](deploy/接入与验收.md)；火山采购范围、同机/托管数据库、IAM权限、HTTPS媒体域名、CORS、续传及实测清单见 [火山TOS接入](deploy/火山TOS接入.md)。当前不需要购买CDN，旧腾讯TypeA配置已禁用。

## 哪些文件是运行代码

| 位置 | 用途 |
| --- | --- |
| `server.js` | 服务启动、端口错误处理和退出清理 |
| `lib/` | 配置、数据库、登录、上传、报名、投票与后台接口 |
| `web/` | 当前正式前端；所有接口连接本项目后端 |
| `scripts/` | 初始化、代码检查、配置检查、入口配置生成与打包 |
| `deploy/`、`Dockerfile` | 正式环境模板、双应用实例和 HTTPS 入口 |
| `test/` | 自动化验证；使用独立临时目录，不写入实际报名数据 |
| `var/` | 本地数据库、私有上传与初始后台凭据，不进入部署包 |
| `releases/` | 生成的干净部署包与 SHA256 校验文件 |

`public/`、`legacy-backup-*`、`client-review/`、`review-package-*`、`_publish_work/` 为历史或审阅内容，当前服务只提供 `web/`。历史材料保留，部署包按允许清单打包，不带这些副本、密钥、真实数据或已安装的依赖。

本地 SQLite 与正式 PostgreSQL 分开使用。原 `data/*.json` 不自动迁移；数据库初始化记录结构版本，不删除既有数据。后续结构变化应新增迁移版本。

## 开发与交付检查

2.2.3 活动归档更新：后台“数据导出”仅管理员可用，提供甲方备案包和内部留存包，35 项自动检查通过。

- 一次下载包含 7 张 UTF-8 CSV 表（Excel 可打开）：活动汇总、报名与审核、作品与成绩、评委评分、投票记录、关联文件清单、操作记录；附归档说明和 SHA256 校验清单。
- 默认甲方版脱敏姓名和手机号，不包含证件号码、身份证明文件、审核备注和私有存储路径。作品文本由创作者填写，分享前仍需人工核对。内部版保留完整联系信息、证件号码、审核备注和文件路径；两版均不含密码、会话令牌或云密钥。
- 包含本活动全部状态，不受列表筛选影响；取消活动与未关联上传不包含。操作记录完整导出，不受页面最近100条限制。评分表保留每人最新评分，操作记录保留评分修改过程。
- SQLite 使用串行事务，PostgreSQL 使用 repeatable-read 快照；各表的统计口径一致。成绩为导出时的实时结果，不是封榜或获奖名单。无评委评分按0分计算并标注进度。
- 下载为 ZIP 归档，姓名、证件号等文本受 CSV 公式执行保护。手机号和长证件号请按文本列导入 Excel；原始 CSV 和校验文件应一起留存。
- 每个实例同时生成一个归档，管理员每5分钟最多5次请求，超过10万条或64MB范围明确报错，不静默丢弃记录。超大活动请安排数据库备份导出。
- 活动结束后先关闭报名投稿及投票，完成审核评分，再导出两版。视频和证明原文件不包含在数据包内，须另外备份数据库与私有存储。

2.2.2 稳定性更新：32 项自动检查覆盖以下行为。

- 草稿依次保存并携带版本，旧页面修改返回冲突提示，避免覆盖新资料。
- 报名资格审核、作品审核与投稿采用一致的作者锁；阶段开关和截止时间在写入事务内复核。
- 扫码确认可安全重复提交；完成响应丢失时，核验原浏览器已消费的扫码请求与实际登录身份后恢复。二维码仍只消费一次。
- API 异常内容返回明确的客户端错误；页面与上传请求设置等待上限。缓存无响应时在 5 秒内失败并重新连接，退出时一次性清理资源并保留错误。
- 本地分片写入与合并按任务排队，完成后拒绝迟到分片，并清理失败的临时文件。
- 该历史版本曾升级腾讯云SDK；2026-10-18本地适配已移除COS/腾讯STS依赖，历史上改用ali-oss 6.23.0；2026-10-19已由官方TOS/STS原生SDK接替。当前浏览器SDK从锁定源码构建并由本站提供，云上传时才加载。锁文件与工作区配置须随部署来源保留。

2026-10-09 生产依赖审计未发现已知漏洞（此前 14 项）。这不替代云端验收；真实微信授权、PostgreSQL 双实例并发、OSS/CORS、容器启动、备份恢复与目标规模压力测试，仍须在正式资源接通后完成。
